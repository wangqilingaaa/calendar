## 待确认 / 注意事项

- DeepSeek API Key 写在前端存在泄露风险，正式上线建议改为后端代理或云函数。
- 微信小程序后台需添加 `https://api.deepseek.com` 到 request 合法域名（开发阶段可勾选「不校验合法域名」）。
- 微信同声传译插件需在小程序后台「设置 → 第三方服务 → 插件管理」中添加，并确保 manifest 中的 version 与后台一致。
