# 2026-08-11

## AI 智能添加：告诉 AI「我」的身份
- 问题：用户用 AI 录入「我喝水」时，后端不知道「我」是谁，AI 返回的 person 多为"我"或 identity_tag，前端 `resolvePerson` 对"我"无匹配 → 落库 person='both'（共同），不符合预期。
- 修复（2 个文件）：
  1. `api/ai.js`：`parseDiaryByText(text, myIdentity)` 新增参数，把当前登录用户的 identity_tag 以 `my_identity` 字段传给后端 `/ai/diary/parse`，让后端提示词能把「我」解析成正确身份。
  2. `pages/index/index.vue`：
     - 新增 `import { getUser } from '@/store/auth.js'`，setup 内算 `myTag = identity_tag || username || '我'`（与 date-detail-modal 保持一致）。
     - `processAiText` 调用 `parseDiaryByText(text, myTag)`。
     - `resolvePerson` 增加前端兜底：`我`/`自己`/`me` → `myTag`。
- 注：这是双保险——后端若已用 my_identity 解析出正确 identity_tag 则走精确匹配；若后端忽略或仍回传"我"，前端也能兜底成当前用户身份。

## 扩展：/ai/diary/parse 现传入完整 persons 列表 + my_identity
- `api/ai.js` `parseDiaryByText(text, myIdentity, persons)`：第三参传 `persons`，请求体新增 `persons`（映射成 `{id, name}`，仅传 id/name 精简体积）。
- `pages/index/index.vue` 调用改为 `parseDiaryByText(text, myTag, persons.value)`。
- 目的：让后端 AI 在解析时，既知道"我"=当前身份（my_identity），也知道全部合法 person 值（persons 含自己/绑定用户/both），从而把文本里的人物准确映射成对应的 identity_tag，减少前端兜底依赖。
