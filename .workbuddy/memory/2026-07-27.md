# 2026-07-27

## AI 能力改为后端代理

为解決 App/H5 打包后无法直连 DeepSeek（跨域、Key 暴露）的问题，将前端 AI 调用改为后端代理接口：

- `api/ai.js` 重写：
  - 移除前端硬编码 DeepSeek API Key 和 `uni.request` 直连逻辑。
  - `parseDiaryByText(text)` 改为 `POST /ai/diary/parse`，传入 `{text, event_names}`。
  - `generateTipsByMonthData(monthData)` 改为 `POST /ai/diary/tips`，传入 `{month_data, event_names}`。
  - 保留微信小程序语音插件 `getSpeechRecognitionManager`。
- `pages/index/index.vue`：适配新签名，移除 `aiModalContext`。
- `components/ai-input-modal/index.vue`：适配新签名，移除 `context` prop。
- `api/config.local.js` / `api/config.local.example.js`：移除 DeepSeek API Key 配置说明。
